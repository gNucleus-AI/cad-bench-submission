# Frozen CAD-Bench v1 submissions

This directory is the immutable archive of accepted third-party v1 manifests.
New v1 submissions and updates are closed. CI rejects later changes under this
directory; submit new results against CAD-Bench v2 under `submissions/v2/`.

The historical v1 leaderboard also contains the first-party matrix runs listed
in [`baselines/v1.json`](../../baselines/v1.json). Those runs are intentionally
recorded as baselines rather than contributor submissions.
